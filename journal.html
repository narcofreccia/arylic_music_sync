Decisions

2026-08-07 — Single flat package (no monorepo): no shared-types consumer exists; promoting to a workspace later is mechanical.

2026-08-07 — reqwest built with .no_proxy() and no TLS features: all device traffic is plain LAN HTTP; a system proxy must never swallow it.

2026-08-07 — Remove-password keeps the profile (hash → None) instead of un-configuring, so the wizard doesn't re-trigger.

2026-08-08 — Group Guard defaults stay unfrozen until the FR-23 spike lands; to_query() and role derivation are the two cheap-to-rewrite chokepoints.

2026-08-08 — Exploring whether Spotify-everywhere is achievable without Google Home by capturing Spotify ourselves (librespot Connect receiver) and re-sending to all LP10s via AirPlay 2 (protocol-level sync; the LP10 is an AirPlay 2 receiver). Feasibility spike underway — would expand the app from LAN orchestrator into an audio server; AirPlay-2-sender + Windows support are the open risks.

2026-08-08 — FR-23 spike / architecture pivot: real LP10s (firmware AR241CE_9243, LibreWireless LS6 module) have NO Linkplay httpapi (404). Native control = LibreWireless Luci (TCP 7777 + mutual TLS 1.2, client cert from the open-source LSCommunicator SDK, 10-byte header + JSON, MessageBox command catalog). Proven live: TLS auth, DevInfo, per-device volume read/write, DDMS M-SEARCH topology (State/NETMODE wired-vs-wifi/MRAMode). Grouping = Luci cmd 100 ASCII verbs (SETMASTER/SETSLAVE/JOINALL/SETFREE) + DDMS ooh-master/groupid/ssid dance — grammar recovered, full formation to build+audio-verify in M4. Details in docs/firmware-notes.md. UPnP (49494) works as a fallback for per-device control.
